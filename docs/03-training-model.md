# 03. Modelo de entrenamiento

## 1. Unidad básica

La unidad central no es el "juego", sino el **ejercicio entrenable**.

Un ejercicio entrena una o varias competencias mediante una consigna concreta, una restricción y una observación posterior.

## 2. Ciclo pedagógico

**Preparar → Ejecutar → Observar → Repetir/Variar → Integrar**

### Preparar
Explicar solo lo necesario para jugar.

### Ejecutar
La atención se dirige al problema o foco del ejercicio.

### Observar
Se revisa qué ocurrió mediante criterios concretos.

### Repetir/Variar
Se consolida el mismo foco o se modifica una variable.

### Integrar
Las habilidades aisladas aparecen posteriormente dentro de tareas más complejas.

## 3. Progresión

La dificultad no debe depender exclusivamente del tiempo. Puede aumentar por:

- número de variables simultáneas;
- memoria necesaria;
- velocidad;
- precisión física;
- restricciones;
- exposición;
- incorporación de personaje;
- incorporación de relación;
- objetivo dramático;
- interacción con otra persona;
- necesidad de justificar cambios;
- integración narrativa.

`difficulty` estima de 1 a 5 la complejidad global para selección y filtrado.
`progression_steps` describe la escalera pedagógica del ejercicio y puede
contener entre tres y siete pasos. No es obligatorio que cada ejercicio use
los cinco valores de dificultad ni que dos ejercicios tengan el mismo número
de pasos.

## 4. Ejemplo de progresión: mímica

Nivel 1: objeto único.

Nivel 2: peso y tamaño definidos.

Nivel 3: varios objetos con posiciones persistentes.

Nivel 4: actividad física completa.

Nivel 5: actividad + personaje.

Nivel 6: actividad + personaje + objetivo.

Nivel 7: integración en escena con compañero.

## 5. Ejemplo de progresión: personaje

Nivel 1: centro corporal.

Nivel 2: centro + velocidad.

Nivel 3: añadir energía.

Nivel 4: añadir voz.

Nivel 5: añadir actitud.

Nivel 6: añadir relación.

Nivel 7: sostener personaje dentro de una escena.

## 6. Sesiones

Una sesión equilibrada puede combinar:

1. activación;
2. agilidad o percepción;
3. foco técnico;
4. integración escénica;
5. reflexión breve.

La V0 no necesita imponer siempre esta estructura, pero el generador debe poder utilizarla.

Las reglas ejecutables del constructor se definen en
`docs/12-session-builder.md`. Como principio, se reserva aproximadamente un
20 % del tiempo elegido para transiciones y autoevaluación.

## 7. Individual vs colectivo

### Adecuado para práctica individual
- mímica;
- cuerpo;
- voz;
- energía;
- asociación;
- personaje;
- storytelling;
- detonadores;
- observación;
- justificación con estímulos preparados.

### Mejora sustancialmente con compañero
- escucha real;
- aceptación interpersonal;
- status relativo;
- relación;
- construcción compartida;
- group mind;
- foco colectivo.

La app debe reconocer esta diferencia y no fingir que ambos contextos son equivalentes.
