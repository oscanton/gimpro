# Gimpro MVP v0.1.0

Primera versión MVP de Gimpro, un gimnasio local-first de entrenamiento para
improvisación teatral.

## Funciones principales

- veinte ejercicios con progresión pedagógica;
- sesiones rápidas de 5, 10 y 20 minutos;
- modo solo, pareja y grupo;
- temporizador, autoevaluación, repetición y “Más difícil”;
- historial de práctica local;
- instalación PWA y funcionamiento offline;
- navegación mobile-first y soporte básico de accesibilidad.

## Pruebas

- catálogo validado mediante JSON Schema;
- ocho pruebas unitarias;
- flujo E2E en Chromium y WebKit;
- auditoría axe-core sin infracciones graves en Inicio;
- recarga offline verificada en Chromium;
- build de producción por debajo del presupuesto acordado.

## Probar

En Windows, ejecutar `gimpro.bat` y elegir servidor local o GitHub Pages.

La versión publicada estará disponible en:

https://oscanton.github.io/gimpro/#/home
